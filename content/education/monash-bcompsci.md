## Overview

I completed a Bachelor of Computer Science at Monash University in July 2026 (graduating October 2026), majoring in **Algorithms & Software** (formerly Advanced Computer Science).

- Implemented advanced string and number-theoretic algorithms from scratch in Python — Knuth-Morris-Pratt, the Z-algorithm, Boyer-Moore, Ukkonen's suffix tree construction, Rabin-Karp rolling hashes, and Miller-Rabin/Fermat primality testing — on top of core data structures and algorithms (queues, stacks, Dijkstra's).
- Built full-stack web apps (Angular, Node.js, Express.js, MongoDB, Firebase) and native Android apps (Kotlin, MVVM).
- Designed ERDs and wrote SQL/PL-SQL (Oracle); applied OOP/SOLID principles extending an existing Java codebase in a team of three.
- Final-year capstone: **Mogo**, a ridesharing app for Monash students, built with a team of four — see the [project page](/projects/proj-mogo/).
