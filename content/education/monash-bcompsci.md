## Overview

I completed a Bachelor of Computer Science at Monash University in July 2026 (graduating October 2026), majoring in **Algorithms & Software** (formerly known as Advanced Computer Science).

## Object-oriented programming & software design

Learned and applied core OOP and software design principles — SOLID, encapsulation, abstraction, inheritance, and polymorphism — including extending an existing Java codebase without modifying it. Worked in a team of three, using UML diagrams (Lucidchart) to plan the design before implementation.

## Algorithms & data structures

Implemented common data structures and algorithms (queues, stacks, Dijkstra's algorithm) before moving on to more advanced, research-level string and number-theoretic algorithms — including Knuth-Morris-Pratt, the Z-algorithm, Boyer-Moore, Ukkonen's suffix tree construction, Rabin-Karp rolling hashes, and the Miller-Rabin/Fermat primality tests — implementing each of them from scratch in Python.

## Databases

Learned to design ERDs and relational schemas from a business case, and to write SQL and PL/SQL (Oracle), with some exposure to translating relational designs into MongoDB.

## Full-stack & mobile development

Built full-stack web applications using Angular, Node.js, and Express.js, with MongoDB and Firebase for data and hosting. Separately, built native Android apps using Kotlin and the MVVM architecture pattern.

## Capstone project

As my final-year project, I worked in a team of four to build **Mogo**, a ridesharing app for Monash students — read more on my [projects page](/projects/proj-mogo/).

## Teamwork & tools

Worked in small teams using Git-based version control (GitHub, GitLab), Agile/Scrum practices with Jira, and automated testing with Pytest.
